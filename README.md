# Micah Blanton — Portfolio

A single-page portfolio with a **trippy** look: P5.js background (morphing blobs, particles, wave ribbons, mouse-reactive glow) and trippy typography/UI.

## Contents

- Resume-derived sections: Summary, Highlighted Projects, Core Competencies, Professional Experience, Education, Certifications, Honors & Awards, Activities, Additional Information
- Contact
- Links

## Stack

- **P5.js** (CDN) — canvas background
- **HTML/CSS** — layout, Syne + Space Grotesk fonts, gradient text, glitch effect, hover states

## Customize

- **sketch.js** — blob count/size, particle count, wave speed, colors (HSB)
- **styles.css** — `--rainbow-*` and `--bg-dark` for palette
- **index.html** — copy, links, sections
